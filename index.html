How it is built

The workflow runs in n8n, behind a single webhook. Five code steps do the deterministic work: validation, year-over-year variance, the planning rules, the sole-prop versus S-corp model with 2026 figures from Rev. Proc. 2025-32, and the authority list.

One model call writes the narrative. It sees only the computed figures and the authorities attached to each rule. A final code step removes any citation outside that list, cross-checks every dollar amount the AI wrote against the computed data, and marks each item for CPA review. If the model is unavailable, the memo still renders from the rule engine's own wording.
